# P09 — 후속 과제 일괄 정리

## 목표

P06~P08에서 "발견했지만 범위 밖"으로 남긴 항목들을 닫는다. 대부분 **한쪽만 고쳐 루프가 열려
있는** 것들이다 — 퇴사 처리는 막았는데 발급은 안 막혔다든지, 서버가 분모를 안 줘서 화면이
"0%"를 성과 실패처럼 보여준다든지.

## 결정 사항

### 법령 — P08의 미결 질문이 1차 출처로 확정됐다(결론이 뒤집힘)
- 질문: **근로자 명부(근기법 §41)·계약 서류 3년 보존(§42)이 5인 미만 사업장에도 적용되는가?**
- 2차 출처(나무위키 요약표·법률 블로그 2곳)는 전부 "별표1 목록에 없다 → 미적용"으로 읽혔다.
  **그러나 법제처 원문(근로기준법 시행령 [별표 1], 개정 2018.6.29) PDF를 직접 추출해 확인한 결과
  제2장 근로계약 항목에 `제35조부터 제42조까지의 규정`이 명시돼 있다** — 즉 **41·42조는 포함,
  4명 이하 사업장에도 적용된다.**
- 파급: P08이 "노무사 확인 전에는 스키마를 확정하지 말 것"으로 미뤄둔 항목이 해소됐다.
  소프트 삭제(`left_at` 보존) 설계가 법적으로도 옳았고, **보존기간 경과분 파기 정책**은
  "나중에 볼 것"이 아니라 실제 의무로 승격된다(3년 — 기산일은 시행령 §22② "퇴직한 날").
- 교훈: 2차 출처 3건이 일치해도 1차 출처와 반대일 수 있다. 법령은 원문만 근거로 쓴다.

### 계정 메일 — 어디까지 되고 어디부터 사용자 몫인지 실측으로 갈랐다
- Identity Platform API로 **제목·본문 템플릿 수정은 거부된다**(`EMAIL_TEMPLATE_UPDATE_NOT_ALLOWED`).
  필드별로 좁혀 확인: 제목 ❌ / 본문 ❌ / **발신 이름 ✅ / 기본 언어 ✅**.
  구글 기본 발송(`method: DEFAULT`)을 쓰는 동안은 템플릿이 잠긴다.
- 적용한 것: `defaultLocale: ko`(제목·본문이 한국어 기본 템플릿으로 전환) +
  발신 이름 `라이즈 컨디셔닝`(종전엔 이름 없이 프로젝트 ID만 보였다).
- **스팸함 원인은 템플릿이 아니라 발신 도메인**이다 — `noreply@rize-218c1.firebaseapp.com`은
  구글 공용 발신자라 람이 소유한 도메인과 DKIM 정렬이 없다. 신규 프로젝트의 트랜잭션 메일을
  Gmail이 의심하는 전형적 조건이라, 템플릿을 아무리 다듬어도 근본 해결이 안 된다.
- 해결 경로 둘 다 **람의 입력이 필요**하다: (a) 자체 SMTP 연결(소유 도메인 발신 → DKIM 정렬 +
  템플릿 잠금도 함께 풀림) (b) Firebase 콘솔에서 수기 편집(스팸은 그대로).
  준비해둔 한국어 HTML 템플릿(table 레이아웃·bulletproof 버튼·다크모드 반전 대비)은
  스크래치패드에 보관 — SMTP가 연결되는 즉시 그대로 적용 가능하다.

### 어드민
- 로그인 버튼의 lucide `LogIn` 아이콘 제거 — 화면에 로그인 버튼이 하나뿐이라 아이콘이 구분에
  기여하지 않고, 문 모양 픽토그램이 한글 라벨 앞에 붙어 기호처럼 읽혔다.

### 앱 UI/UX — 조사 결과 실제 대상이 갈렸다
- **사용자에게 보이는 이모지는 0건**이다. 검출된 4건은 전부 주석·문서화 문자열이었다
  (`⚠️` 2건, `✓` 2건). 즉 "이모지를 SVG로 교체"는 대상이 없다.
- 아이콘 혼용은 **내 집계 오류였다(정정)**. 내가 "22곳"이라 셌던 건 `grep "Icons\."`가
  자체 세트인 `RiseIcons.home`까지 매칭한 결과다. 감사관이 전수 검색으로 잡아준 **실제 2곳**
  (`code_screen`의 `arrow_back`, `my_screen`의 `logout`)이 전부였고, 둘 다 교체해 지금은 0건이다.
  교훈: `Icons\.`처럼 짧은 패턴은 접두어가 붙은 식별자를 함께 삼킨다 — 집계 전에 표본을 봤어야 했다.
- **진짜로 큰 것은 폰트였다.** `ThemeData.fontFamily = 'Pretendard'`가 선언돼 있는데 파일이
  저장소 어디에도 없어(pubspec `fonts:` 없음·`assets/` 없음) 전 화면이 폴백 폰트로 렌더되고
  있었다. 0.5pt 단위로 맞춘 타입 스케일이 Pretendard의 x-height·한글 자간을 전제한 값이라,
  이걸 두고 타이포를 손대면 전부 잘못된 기준 위의 미세조정이 된다. 가변폰트 1개(6.4MB, OFL)로
  번들 — 정적 6종(9MB)보다 작고, Flutter가 `FontWeight`를 `wght` 축에 자동 매핑한다(공식 문서 확인).

## 후속 작업

- (해소) 앱 실화면 점검은 **안드로이드 에뮬레이터**(Pixel 6 / API 32)를 직접 만들어 완료했다 —
  물리 기기도 AVD도 없었지만 SDK에 시스템 이미지가 있어 AVD를 생성했다(JDK 11이 걸려
  Android Studio 번들 JDK 21로 우회). adb로 탭·텍스트 입력·캡처가 전부 되므로 iOS 시뮬레이터의
  입력 수단 부재 문제가 사라졌다. 로그인 → 인증 → 매칭 → 연결 → 홈 → 예약 확정 → 마이까지
  **화면을 눈으로 보며** 통과.
- ~~접근성 배율 1.35 초과는 고정 높이 3곳 때문에 잘린다~~ **(측정 결과 사실이 아님 — 정정)**
  이 메모는 탭바를 최소 높이로 고치기 **전** 상태를 서술한 것이었다. 번들 폰트를 실제 로드해
  배율 1.35·2.0·3.0·4.0에서 세 곳(탭바 · 체형 사진칸 130 · 인바디 차트 80)을 전부 재보니
  **어디서도 오버플로하지 않는다** — 탭바는 `minHeight`로 바뀌었고, 나머지 둘은 내용(약 42px)
  대비 여유가 크다.
  따라서 1.35 상한은 **이 세 위젯이 강제하는 값이 아니다.** 다만 전 화면을 다 재보지는 않았으므로
  상한을 올리는 건 별도 판단이다 — 근거 없이 올리면 확인하지 않은 화면에서 깨진다.
  교훈: 보고서에서 옮겨 적은 "남은 빚"도 시간이 지나면 사실과 어긋난다. 측정으로 확인하고 고쳤다.
- `pass_list`·`my_bookings_list`의 상태 배지는 서버가 미지의 긴 `status` 문자열을 주면
  이론상 넘칠 수 있다(배지는 잘리면 뜻이 사라져 일부러 비유연으로 뒀다).
- **로그인 화면에 개인정보처리방침·이용약관 링크가 없다** — 스토어 심사 요건. 동의 토글은 로그인
  **후** 마이 탭에만 있다.
- `range` 파라미터 미구현이라 `noshow_d`/`hw_d`는 전 기간 집계(계약에 경고 명시)
- Firestore **쓰기** 경로엔 빈 ID 가드가 없다(읽기 11종만 정규화)
- 보존기간 파기 배치 — 근기법 3년이 **적용 확정**됐으므로 실제 의무

### 실기기(에뮬레이터) 점검에서 찾은 것 — 화면을 봐야만 나오는 결함

1. **하단 탭바 1px 오버플로**(`BOTTOM OVERFLOWED BY 1.00 PIXELS`) — **Pretendard 번들이 만든 회귀**다.
   가운데 촬영 탭의 레이아웃 높이가 원 48 + 라벨 줄높이인데, 번들 폰트의 9.5pt 줄높이가 폴백보다
   미세하게 커져 63px가 되면서 `height: 62`를 넘겼다. 폴백 폰트로 도는 위젯 테스트에서는
   재현되지 않아 **아무 게이트도 잡지 못했다**. 고정 높이 → **최소 높이**로 바꾸고,
   번들 폰트를 실제 로드해 배율 1.0/1.15/1.35에서 오버플로를 확인하는 테스트를 붙였다.
2. **안내 문구의 전화번호가 미포맷** — 입력란 힌트는 `010-1234-5678`인데 안내는
   "01012345678로 보냈어요"였다. 표시 전용 포맷터를 추가(정규화 함수와 목적이 달라 분리).
3. **바텀시트가 하단 탭바를 덮지 못했다** — 셸 내부 Navigator에 떠서 스크림 위에 탭바가 남고,
   예약 확정 전에 다른 탭으로 빠져나갈 수 있었다. 시트 6곳 전부 `useRootNavigator: true`.

관찰(미수정): 세션 복원 후 홈 헤더가 "김민지 님"이 아니라 센터명으로 떨어진다 —
`/v1/me`에 이름이 없어서다. **어드민도 같은 필드를 기다리고 있어**(헤더 표시) 계약에
`Me.name`을 추가하는 게 두 계층을 한 번에 해결한다. 예약 화면 상단이 지난 시간대(지남)로
절반쯤 차는 것도 남는다.

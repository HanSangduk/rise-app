# 라이즈 브랜드 자산 (P19)

원본: 람이 준 브랜드 보드(`~/Downloads/rise.jpeg`)의 R 마크. JPEG 크롭이 아니라 **벡터 재현**이다
— 원본에서 R이 200px 남짓이라 1024px 아이콘으로 확대하면 뭉개진다. 재현 과정과 좌표계의 유래는
`rise-mark.svg` 헤더 주석에.

## 색

| 용도 | 값 |
|---|---|
| 네이비(획) | `#3B4C60` |
| 베이지(점) | `#CEBBAA` |
| 크림(배경) | `#F6F4EF` |

앱 테마의 `AppColors.red`(#E is 계열)와는 **다른 팔레트**다 — 마크는 브랜드 보드의 원색을 그대로
쓴다. 마크를 앱 색으로 다시 칠하지 말 것.

## 파일

| 파일 | 무엇 |
|---|---|
| `rise-mark.svg` | 마크 원본(소스 오브 트루스). 배경 없음, viewBox가 마크에 밀착 |
| `gen/appicon-master.png` | 1024×1024, 크림 배경 풀블리드, 마크 높이 60% — iOS·범용 |
| `gen/appicon-fg.png` | 1024×1024 투명, 안드로이드 적응형 **전경**. 마크가 세이프존(중앙 66/108 원, 626px) 안 |
| `gen/appicon-mono.png` | 전경과 같은 배치의 단색 — 안드로이드 13+ 테마 아이콘(알파만 쓰임) |

적응형 **배경**은 이미지가 아니라 단색 `#F6F4EF`로 지정한다(파일 불필요).

## 재생성

`gen/`은 scratchpad의 `icons.html`을 headless Chrome으로 렌더한 것이다. 마크를 고치면
`rise-mark.svg`와 `icons.html`의 MARK를 **함께** 고치고(중복 정의 — 아이콘 쪽은 색·배치
파라미터가 달라 분리했다), 투명 배경은 `--default-background-color=00000000` 플래그가 필요하다.

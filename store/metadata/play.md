■ 수업 예약
- 담당 코치의 시간표를 보고 원하는 시간에 바로 예약
- 코치 휴무일·마감 시간은 예약 전에 미리 표시 — 눌러보고 거절당하는 일이 없어요
- 예약 취소 기준(취소 가능 시간)도 화면에서 바로 확인

■ 오늘의 홈워크
- 코치가 내준 홈트레이닝을 체크리스트로 확인하고 완료 체크
- 세트·횟수·주의사항까지 코치의 처방 그대로

■ 몸의 변화 기록
- 인바디(체성분) 수치 — 체중·골격근량·체지방률 — 를 입력하면 추이 그래프로 한눈에
- 체형 사진을 같은 각도로 촬영하고 날짜별로 비교 — 수평계·격자 가이드 제공
- 인바디 결과지를 촬영하면 수치가 자동 입력(OCR)

■ 수업 기록
- 매 수업의 운동·중량·코치 메모를 앱에서 다시 확인

■ 회원권 관리
- 잔여 회차·유효기간을 실시간으로 확인
- 여행·부상 시 일시정지 신청도 앱에서 바로
- 결제 내역·전자계약서 확인, 재등록 요청까지

■ 셀프 체크인
- 데스크 QR을 스캔하면 출석 완료
